# 📧 Otomatik Fiyat Takip & HTML E-posta Bildirim Botu

Belirlenen ürünlerin ve verilerin fiyat değişimlerini takip eden; hedef fiyat yakalandığında kullanıcıya özel **HTML tasarımlı anlık e-posta alarmı** gönderen Python otomasyon sistemi.

## 🚀 Öne Çıkan Özellikler
- **Otomatik Takip:** Hedef ürün ve fiyat eşiklerini sürekli izleme.
- **Şık HTML Bildirim Kartları:** Gmail SMTP altyapısı ile mobil ve masaüstünde okunaklı e-posta uyarıları.
- **Akıllı DNS Çözümleme:** `dnspython` entegrasyonu ile kısıtlı ağlarda bile kesintisiz sunucu bağlantısı.

## 🛠️ Kullanılan Teknolojiler
- **Dil & Kütüphaneler:** Python, `smtplib`, `dnspython`, `requests`, `python-dotenv`
